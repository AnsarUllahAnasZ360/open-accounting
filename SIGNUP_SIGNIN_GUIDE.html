🔐 Sign Up & Sign In Implementation

✅ Status: Complete and committed to ehsan-dev branch
Commit: feat: implement separate signup and signin flows with proper error handling
Changes: 2 new components, 2 new pages, 3 components updated, comprehensive error handling

Problem Fixed

Previously, the single sign-in/sign-up form tried both signin and signup in sequence. Non-existent users saw:

❌ "Workspace unavailable - Your last workspace was suspended or deleted..."

This was confusing because it didn't explain the actual issue: the user account didn't exist.

Solution Implemented

Separated signup and signin into two distinct flows with proper error messages, validation, and user guidance.

User Flows

👤 New User Creating Account
Visit /sign-up
Enter email (required)
Enter password (8+ characters)
Confirm password (must match)
Enter name (optional)
Submit → redirect to /dashboard
✅ Account created successfully
🔑 Existing User Signing In
Visit /sign-in
Enter email (required)
Enter password (required)
Submit → redirect to /dashboard
✅ Signed in successfully

If credentials invalid: ❌ Invalid email or password. If you don't have an account yet, please sign up.

📧 Invited User Joining Workspace
Receive invite link with token
Visit /invite/[token]
See workspace details and access level
Email pre-filled (locked) and readonly
Create password, confirm password, optional name
Submit → account created + invite accepted
Redirect to /dashboard
✅ Workspace membership activated

Error Handling

Scenario Error Message Where Shown
Empty email field Email is required Browser validation
Password < 8 characters Password must be at least 8 characters SignUpForm field error
Passwords don't match Passwords don't match SignUpForm confirmation error
Email already has account Unable to create account. The email may already be in use... SignUpForm error card
Invalid credentials (signin) Invalid email or password. If you don't have an account yet, please sign up. SignInForm error card
